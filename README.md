## Hound

A single-page web app prototype: a fitness/health-data app for friend
challenges (step races, streaks, and a "Hunter & Hunted" chase based on
GPS distance from Apple Health / Health Connect).

No build step or server required — it's plain HTML/CSS/JS with the
Inter font and Phosphor icons vendored locally under `vendor/`.

To run it locally:

```
python3 -m http.server 8000
```

then open http://localhost:8000 in a browser (or just open `index.html`
directly). All data shown is static sample data — there's no backend.
